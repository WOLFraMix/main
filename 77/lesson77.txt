Смысл в чем? Количество строк, которые нам надо вывести равно 2n - 1
Например, для ромба со стороной в 4 будет 4*2 - 1 = 7. Можете проверить сами.
Так что самый главный цикл у нас будет пока i не достигнет 2n - 1
Заводим переменную offset, типа смещение.
Для каждой строчки нам нужно вывести 2 раза #
(первая и последняя строки это частный случай, когда оба знака находятся на одном и том же месте)
И что мы замечаем? Что # в первой строке будет расположен на месте n
(а точнее, n + offset, но т.к. в первой строке смещение = 0, то выходит, что на позиции просто n)
А далее # расходятся на одну позицию в разные стороны, т.е. для второй строки нам надо нарисовать 2 знака #
первый будет на позиции n - offset (offset мы увеличили перед там как приступить к выводу второй строки),
а второй будет на позиции n + offset.
В третьей строке позиции # будут опять n-offset и n+offset, но т.к. мы опять увеличили offset, то решеточки опять разъехались.
Мы увеличиваем offset, пока не дойдём до отрисовки нижней части, а это случится когда i пересечёт n.
Как только мы пересекли мы offset начинаем уменьшать, чтобы позиции, на которых находятся решетки, начали сужаться.

package main

import (
	"bufio"
	"fmt"
	"os"
	"strconv"
)

func printDiamond(n int) {
    fmt.Printf("Мой бриллиант:\n")
	var offset int
	for i := 1; i <= (2*n - 1); i++ {

		for j := 1; j <= n+offset; j++ {
			switch {
			case j != n+offset && j != n-offset:
				fmt.Print(" ")
			default:
				fmt.Print("#")
			}
		}

		// сначала мы идём на расширение, потом на сужение
		if i >= n {
			offset--
		} else {
			offset++
		}
		// новая строка
		fmt.Printf("\n")
	}
}
